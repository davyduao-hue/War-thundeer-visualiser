Download WTArmourVision.exe for the standalone Windows x64 application. No Python, CMake or Visual Studio is needed to run it. The synthetic demo database is embedded and copied to the user's local application data folder on first use. The ZIP additionally includes data and licence files.

This is an unsigned research build. Native control centre, telemetry-only overlay and synthetic offline plate analysis are implemented. Game telemetry and Windows behaviour require real-world validation. Demo mode starts enabled: disable it on Dashboard to attempt a connection to a running aces.exe game window and localhost port 8111 in borderless mode. Current game-rule compliance has not been verified; this release does not add live weakspot targeting.

No verified vehicle armour database, automatic ammunition detection, damage prediction or computer vision is included. All demo values are synthetic. This is not the complete product described in the original specification.
